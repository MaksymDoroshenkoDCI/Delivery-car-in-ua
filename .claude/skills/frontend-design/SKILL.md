# Правила дизайну інтерфейсу
- Завжди використовуй сучасну палітру кольорів.
- Додавай плавні переходи (transition-all duration-200) для hover-ефектів.
- Роби закруглені кути кнопок і карток (rounded-lg або rounded-xl).
- Уникай нудних дефолтних стилів браузера.
